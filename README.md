Hiper-tetris
Juego Tetris en typescript, funcional y testeable mediante vitest. 
Pasos para utilizarlo en tu computadora:

1. Ejecutar:
npm init -y

Esto genera el archivo:
package.json

2. Ejecutar:
npm install --save-dev typescript

Verificar la instalación:
npx tsc --version

3. Vitest será utilizado para ejecutar los tests unitarios.
npm install --save-dev vitest

4. Ejecutar:
npx tsc --init

Esto crea el archivo:
tsconfig.json

5. Desde la terminal ejecutar:
npx vitest run
